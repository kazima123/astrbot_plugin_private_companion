# 五子棋与井字棋共同下棋补丁

本分支维护版本为 `7.2.5a`，在上游 7.2.5 基础上保留共同下棋功能，游戏能力版本为
`7.2.5a+game.20261109.2`。上游作者及 AGPL-3.0-only 许可证保持不变。

## 使用方式

- 自然语言请求“陪我下五子棋”或“来局井字棋”，通过已授权的原生工具取得棋桌链接；已有同种未结束棋局时继续原局。
- 支持选择难度和先后手。接续旧局保留该局原难度；链接过期或插件重载后，可请求重新获取同一局链接。
- 网页正常轮流落子，保留五子棋手机选点确认。服务端拒绝自由摆子和单独要求机器人落子。
- 关闭网页会保留棋局；明确要求结束或点击结束按钮才会中止，并记录“中途结束、未分胜负”。
- 邀请使用原主动联系调度和免打扰设置；默认候选概率 18%、冷却 24 小时，有未结束棋局或当日已拒绝时抑制邀请。先邀请，接受后再开局；用户直接要求开局不受邀请冷却限制。

## 对局经历

网页与聊天共用结果保存入口。基本结果不依赖模型，以用户、角色及棋局编号去重，保存实际结果、时间、执棋、难度、步数和棋谱来源。存储失败由原后台维护补写，页面显示保存状态。

终局后沿用原后台维护补充对局时段的真实聊天来源，不推测情绪、因果或已读状态。上下文清空、插件重载和正常重启不删除已保存的棋局经历。

结构化对局经历仍写入陪伴小屋原生记忆服务。若使用 MemoryCompanion 作为主记忆，QQ 聊天继续由该插件采集；本补丁没有迁移旧记忆，也不要求修改 MemoryCompanion 源码。

## 安装与维护

需要在陪伴小屋授权对应游戏并配置可访问的棋桌服务地址。仓库不包含部署者的域名、端口映射、网络凭据或运行数据；这些按实际部署配置。

游戏补丁涉及 10 个生产源码文件及 5 个测试文件，不包含其他独立的记忆整理修复。合并上游更新时保留游戏独立版本和这组回归。主插件、构建工具与发布基线使用维护版本，插件仓库地址指向 `kazima123/astrbot_plugin_private_companion`；已有运行实例需另行部署才会采用这些元数据。

主要回归入口：

```bash
python -m unittest -v tests.test_games_tictactoe tests.test_games_gomoku tests.test_game_native_context tests.test_game_native_web tests.test_game_shared_board tests.test_game_memory_ingestion tests.test_native_services_lifecycle tests.test_proactive_prompt_guidance
node --test tests/test_game_native_page.cjs
```

宿主测试需使用 AstrBot SDK 环境及独立临时数据根，详见贡献指南。测试使用合成棋局和受控模型、发送端；真人 QQ 自然语言表现、实际邀请与实体手机完整对局须单独验收。
